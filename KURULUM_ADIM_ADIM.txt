ARENA CLUB V2.1 – MEVCUT V2.0 ÜZERİNE GÜNCELLEME
================================================

ÖNCE:
- Çalışan oyuna.top/club sistemini veya kullanıcı kayıtlarını silme.
- Coolify Persistent Storage içindeki /app/data volume'unu DEĞİŞTİRME.
- Veritabanı ve dosya volume'u ile GitHub deposunun yedeğini al.
- Mümkünse önce başka bir Coolify test uygulamasına dağıt.

GITHUB'A YÜKLE:
1. GÜNCELLEME ZIP'ini bilgisayarında aç.
2. ZIP içindeki club ve public klasörlerini GitHub'daki
   tasimali422-cell/oyun-platformu deposunun ANA dizinine yükle.
   Dizinler aynı kalmalı: club/platform.js ve public/club.js gibi.
3. GitHub mevcut dosyalar için güncelleme yapacak. Commit changes de.
4. İstersen bunun yerine TAM v2.1 ZIP'ini çıkarıp tüm projeyi
   depoya yükleyebilirsin; dosyaların yerlerini değiştirme.

COOLIFY:
5. Mevcut oyun-platformu-web uygulamasına gir.
6. Environment Variables ve Persistent Storage ayarlarını AYNEN koru.
7. Sağ üstten Redeploy yap, durum Running olunca /health adresini kontrol et.
8. Ardından https://oyuna.top/club adresini açıp Ctrl+F5 ile yenile.

NE TEST EDECEKSİN:
A. Ana sayfada Kızma Birader kartı -> sadece Kızma Birader salonları;
   Klasik Okey kartı -> sadece Okey salonları.
B. Yönetim -> Üyeler -> Rol / Yetki ver -> Moderatör seç -> Kaydet.
   İstersen Yönetici seçeneğini de test et; tam yetki verir, dikkatli ol.
C. Yönetim -> Turnuvalar -> ileri tarihli turnuva oluştur.
   Ana sayfa Yaklaşan Etkinlikler ve Turnuvalar menüsünde görünmeli.
D. Yönetim -> Turnuvalar -> Katılımcılar -> oyuncu ekle.
   Ardından Sonucu doğrula penceresinde yalnız katılımcılar görünür.
   GERÇEK maç doğrulaması olmadan ödül verme.

NOT:
