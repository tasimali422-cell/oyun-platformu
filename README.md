# Oyun Platformu v1.3

- Kompakt Okey masası ve küçük mobil taş çek/at kontrolleri
- Oyun başladığında yan menü gizlenir
- Okey Yazboz paneli oyuncu maç puanlarını gösterir
- Oyuncu adına tıklayınca aynı masadaki oyuncuyla özel mesajlaşma açılır
- Özel mesajlar yalnız iki tarafa WebSocket üzerinden iletilir; kalıcı depolanmaz
- Mevcut Tombala ve Okey sunucu modülleri korunmuştur.
