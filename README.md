# Oyun Platformu v0.8 Tombala

- Tombala odası en fazla 24 oyuncu (performans yük testi gerektirir).
- Çekiliş aralığı 30 saniye. Her çekilen sayı kendi çekilme anından itibaren 30 saniye işaretlenebilir.
- Kartlar 1–12 adet, manuel işaretleme.
- Tombala alanı üstte, oyuncular aşağıda; mobil yerleşim iyileştirildi.
- Kazanma sunucuda çekilen sayılara göre doğrulanır; manuel işaretleme görsel katmandır.
- Okey kuralları değiştirilmedi.
- Oyunlar sunucu belleğindedir, yeniden dağıtımda silinir. Gerçek oyuncu yoğunluğu için test gerekir.
